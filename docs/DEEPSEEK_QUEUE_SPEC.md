# DeepSeekキュー実装（Issue #162）

ピーク時間に投稿された `/deepseek ask ...` と `/deepseek review ...` は拒否せず、元コメントIDと本文ハッシュをIssue内へ記録して予約する。予約は、GitHub Actionsの定期実行によりオフピークになった後で処理する。

`/deepseek cancel <元コメントID>` により未実行の予約を取り下げる。送信予約が確定した後にAPI通信を取り消せるとは扱わない。 `DEEPSEEK_ENABLED=false` の間は予約を保持し、APIは呼び出さない。

GitHub Actionsのスケジュールは遅延・欠落し得るため厳密な開始時刻を保証しない。二重起動を防ぐため、コメント起動と定期起動を同一グループで直列化し、開始済みマーカーのある依頼は再実行しない。秘密情報はIssueへ記録しない。

現行のコードではピーク中は拒否するため、本書はキュー実装がmainへ統合されるまで未実装要件を記録するものである。
